- New MODERN controls (OPTIONS -> CONTROLS, or the game's controller setting): Samus always runs, L aims, R + X / Y / B fire missiles, the grapple and the X-ray, Y rolls into the morph ball.
- The "?" next to CONTROLS shows what every button does in both schemes.
- Item tracker: the map shows where items are, and a window counts what each area still holds (SPOILERS shows everything).
- STATUS tab redesigned: tap a weapon to select it, reserve tanks and an AUTO / MANUAL button.
- The language can now be chosen in the game's own options too, and new languages can be added as text files on the SD card.
