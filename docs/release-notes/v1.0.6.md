- New OPTIONS -> SOUND: the game is louder by default (VOLUME 200 %, up to 400 %, loud peaks softened), and MUSIC and EFFECTS can be set apart.
- Your CLASSIC buttons, ICON CANCEL and MOON WALK now stay as you set them when you load a save state, pick a save file or reset the game.
- HEAVY PHYSICS: the wall jump now rises like a normal jump and pushes you less off the wall, closer to Zero Mission.
- New OPTIONS -> PLAY -> AIR SPIN (off by default): press jump in the air to start spinning, as in Zero Mission, so a fall can end in a wall jump.
